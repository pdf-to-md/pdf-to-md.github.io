FAQ

Is my file uploaded?

Not in free mode. The PDF is parsed in your browser and never sent to our servers. AI mode sends the file to the AI engine for recognition; our servers log only the file name, page count and credits used, and keep neither the file nor the result.

Can it convert scanned PDFs?

Yes, with AI mode. Scans have no text layer, so free mode gets almost nothing out of them. When you pick a file we check it first and suggest AI mode if it looks like a scan.

How well are tables preserved?

Free mode rebuilds tables from text positions and handles regular tables well. For merged cells or tables that span pages, AI mode does better. Output is a standard GFM Markdown table.

How are credits charged?

AI mode charges per page when the conversion starts and refunds automatically if it fails. Credit packs are one-time purchases, no subscription, valid for a year. Free mode never uses credits.

Are there size limits?

Files up to 50 MB. Free mode handles up to 15 MB in the browser. AI mode supports up to 1,000 pages depending on the engine.
