- **Free mode:** runs in your browser, no sign-up, your file never leaves your device.
- **AI mode:** OCR for scanned PDFs, formulas as LaTeX, multi-column layouts.
- **Output:** headings, lists and GFM tables, ready for ChatGPT, RAG, Obsidian or docs sites.
